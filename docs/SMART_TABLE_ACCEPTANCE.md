## 自动化测试规则

1. 每个主按钮至少有一个浏览器级测试，检查点击后的可见结果或网络写入。
2. 每个右键菜单项至少有一个浏览器级测试；涉及数据的动作必须重载页面再次断言。
3. 每个写接口至少有 API/数据库测试，验证权限、输入边界、写入结果和重新读取。
4. CI 同时执行服务端语法、数据库测试、前端构建、浏览器测试、Docker 和 Windows 启动检查。
5. 失败项目不得在本文件或 Issue #11 中勾选。
